# Color Palette Generator

A simple and responsive Color Palette Generator built using HTML, CSS, and JavaScript. This tool generates five random HEX colors and allows users to copy color codes to the clipboard with a single click.

## Project Overview

This project was developed as part of the **Veda Technology Web Development Internship – Day 14 Task**.

The main purpose of this project is to practice random value generation, DOM manipulation, and the Clipboard API.

## Objectives

* Generate random HEX color codes.
* Display five color swatches dynamically.
* Implement click-to-copy functionality.
* Practice JavaScript DOM manipulation.
* Create a responsive and user-friendly interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Generates five random colors.
* Displays HEX codes for each color.
* Click on any color to copy its HEX code.
* Shows a confirmation message after copying.
* Generate New Palette button.
* Responsive design for mobile and desktop.
* Simple and clean user interface.

## How It Works

1. When the page loads, five random colors are generated automatically.
2. JavaScript uses `Math.random()` and `Math.floor()` to generate HEX color values.
3. The colors are dynamically displayed using `innerHTML`.
4. Clicking the Generate New Palette button creates a new set of colors.
5. Clicking on a color copies its HEX code using the Clipboard API.
6. A confirmation message appears after successful copying.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Click the **Generate New Palette** button to generate new colors.
5. Click any color swatch to copy its HEX code.

No additional dependencies or installations are required.
